# Putting cuttit on CreatePie: step by step

**Never share your CreatePie password** with anyone, including in a chat.

## Before you start
1. Email CreatePie (admin@createpie.com) the 4 questions (can international customers pay you, can you use the
   international plan, payout timing, zip downloads). Their answer decides the international price.
2. Download this `createpie/` folder from GitHub to your computer (Code → Download ZIP on the repo page, branch
   `claude/new-york-edita-club-tzgfl4`), and unzip it.

## Option A: let Claude in Chrome do the clicks (desktop only)
1. On your **desktop computer**, install **Claude in Chrome** from the Chrome Web Store and sign in with your Claude account.
2. In Chrome, log in to CreatePie yourself.
3. Open the Claude side panel and paste the prompt below. Upload files yourself when it asks
   (browsers don't let an extension pick files from your computer on its own).
4. Watch it work and approve each step. Check everything before you publish.

```
I'm logged in to CreatePie. Help me set up my academy and one paid course.
Use the text in the COURSE.md I'll paste below, exactly as written.
1. Dashboard -> Website builder: pick a clean, minimal template. Academy name "cuttit".
   Headline "Your reels, edited by Claude." Save as draft.
2. Dashboard -> Payments: stop and let me fill in my bank details myself.
3. Create a new paid course with the title, subtitle, description, price and tags from COURSE.md.
   Ask me to upload the cover image.
4. Create Section 1 "Start here" and Section 2 "The skills", then each lesson from the curriculum table.
   For each lesson's attachment, stop and ask me to upload the file.
5. Don't publish anything. When finished, show me a checklist of what you created.
[paste COURSE.md here]
```

## Option B: do it yourself (about 30 minutes)
1. **Plan:** Dashboard → Billing → choose **Courses** (India: ₹500/month + 10%).
2. **Payments:** Dashboard → Payments → India → add your bank name, account number, IFSC and account type.
3. **Website:** Dashboard → Website builder → pick a minimal template → academy name "cuttit" → headline
   "Your reels, edited by Claude." → add your photo/logo → save.
4. **Course:** create a new course → fill in everything from `COURSE.md` → upload `covers/course-cover.png`.
5. **Lessons:** add Section 1 and Section 2, then one lesson per row in the curriculum table, attaching
   the matching zip from `downloads/`.
6. **Preview** as a student: check that every download works.
7. **Publish**, then send me your academy link (e.g. `cuttit.createpie.com`). I'll point every Buy button on the
   cuttit website to it.
