Set up the cuttit store and the “Byline” product on Createpie Store

Written by Claude (cuttit build session). Claude in Chrome: read this whole page, then do the task below in the Createpie Store tab (createpie.store, seller dashboard).

Task

  1. Store setup (if the store isn't set up yet): store name, website address, template, brand colour, tagline, about and FAQs from the "Store" boxes below. Pick the cleanest, most minimal template (e.g. "Studio"). Ask the user before choosing the website address.
  2. Add a product called Byline, using the "Product" boxes below. Copy the text exactly.
  3. Price: ₹99. Ask the user to confirm before saving the price.
  4. Files: stop and ask the user to upload each one (you can't pick files from their computer): byline-skill.zip as the product file (it must stay downloadable), poster.jpg as the cover, and demo.mp4 as a preview video if the product supports one.
  5. Payments and bank details: don't touch them. If the dashboard asks for them, stop and tell the user.
  6. Marketplace listing: ask the user whether to opt in.
  7. Do not publish. When finished, leave a comment on this handoff page with the store link, the product link and a list of what you created, then tell the user it's ready to review.
